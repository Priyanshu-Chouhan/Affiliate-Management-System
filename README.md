# Affiliate Management System

This repository contains the frontend and backend modules for the affiliate management platform.

## Project Structure

- `client/` - React + TypeScript frontend application
- `server/` - Backend source and Prisma configuration

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

## Notes

- The frontend uses Vite + React + TypeScript.
- Environment variables should be kept in local `.env` files and should not be committed.
- The backend source lives under `server/src/` and Prisma schema under `server/prisma/`.
